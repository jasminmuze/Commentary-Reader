---
name: Room comment sharing
description: Product decision connecting ordinary book comments to reading-room activity without a separate posting action
---

Readers should see their accessible room comments when opening a book normally. Ordinary Public/Friends comments on that book also appear in the author's currently joined rooms for the same canonical book, without requiring a separate Room posting button. Private comments remain author-only. Explicit room-scoped comments do not spread into a different room.

**Why:** The user found separate room posting controls confusing: people commented normally and their reading room appeared inactive. They explicitly asked to make ordinary book commenting participate in room activity. This supersedes the earlier preference to show only explicitly room-linked comments.

**How to apply:** Use current author and viewer memberships for implicit room sharing. Do not copy or permanently backfill comments into rooms. Existing ordinary comments follow the same rule, and leaving a room removes implicit sharing there. Keep blocks and spoiler protections; do not extend this room audience to public profile lists.
