---
name: Room-link store availability
description: Current iOS and Android store availability for Shelfmates room invitations.
---

For room invites, Shelfmates is currently released through the iOS App Store only. Android does not yet have a public Google Play install listing. The iOS listing supplied by the user is https://apps.apple.com/kr/app/shelfmates-social-reader/id6795648309?l=en-GB.

**Why:** Invite links need to offer a real install destination and must not send Android users to a nonexistent store listing.

**How to apply:** Use the iOS App Store URL on iPhone invite pages. On Android, keep links that open an installed app working, but clearly state that the app is currently available on iPhone only until a Play Store listing is provided.
