# Rule

Show recent public highlights and top-level public comments on profiles. Keep replies inside their conversation threads rather than listing them as profile activity.

**Why:** The user expects romantasy reading to generate frequent casual reactions and wants to encourage interaction, while avoiding repetitive, context-dependent replies on profile pages.

**How to apply:** Preserve replies in comment threads, enforce content visibility on profile queries, and retain the app's spoiler and quote-preview safeguards.
